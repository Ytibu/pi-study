# 04 消息历史与上下文准备

版本：Pi **v1.0.0**（`a13d35a74`） · 记录／修订日期：2026-10-25

本模块展开 [第 03 篇](03-Agent基础与最小运行闭环.md) 最小闭环的第二步：用户输入后，Pi 如何加入消息历史、准备上下文与工具说明。

## 1. 按源码职责划分子模块

前四个子模块对应 `packages/coding-agent/src/core/` 中的会话与资源组件，第五个跟进 `packages/agent/src/` 中的底层运行实现。

| 子模块 | 真实代码边界与输出 |
| --- | --- |
| [04.1 SessionManager：会话记录与投影](04-1-SessionManager会话投影.md) | `session-manager.ts` 从会话条目生成当前分支的有效消息 |
| [04.2 ResourceLoader：项目资源加载](04-2-ResourceLoader资源加载.md) | `resource-loader.ts` 发现并缓存项目约定、技能与提示词等资源 |
| [04.3 SystemPrompt：系统指令构建与差量更新](04-3-SystemPrompt指令构建.md) | `system-prompt.ts` 将指令选项构建为分区，并计算更新补丁 |
| [04.4 AgentSession：输入处理与请求装配](04-4-AgentSession输入与装配.md) | `agent-session.ts` 处理当前输入、选择工具、安装请求准备钩子 |
| [04.5 Agent 与 AgentLoop：请求上下文准备](04-5-AgentLoop请求准备.md) | `agent.ts`、`agent-loop.ts` 合并消息、生成工具声明并交给模型运行时 |

历史消息、系统指令和工具说明分别在这些组件之间传递；本模块按代码的职责和调用关系解释它们。

## 2. 初始化阶段：准备依赖与已有状态

[sdk.ts](../../pi/packages/coding-agent/src/core/sdk.ts) 的 `createAgentSession()` 是这些组件的装配入口。主要调用顺序如下，省略模型选择等旁支：

```text
createAgentSession()
  → 未注入加载器时：创建 DefaultResourceLoader 并 reload()
  → SessionManager.buildSessionContext()
  → new Agent({ initialState: { messages: existingSession.messages, ... }, ... })
  → new AgentSession(...)
      → 安装事件订阅和请求钩子
      → _buildRuntime()，准备工具与基础指令选项
```

资源加载和已有会话恢复主要在这个阶段完成，不是每次输入都重新扫描文件、重新创建会话。

## 3. 输入与请求阶段：沿真实调用链阅读

```text
AgentSession.prompt(text)
  → 输入处理、模板展开、模型与认证检查
  → 构建 user 消息
  → _preparePromptAndToolLoadout()：更新工具状态，生成指令分区补丁
  → _runAgentPrompt() → Agent.prompt()
      → 获取状态快照与循环配置
      → runAgentLoop()：计算工具声明变化、合并消息并发出消息事件
      → runLoop()
          → prepareRequest：AgentSession 重新取得 SessionManager 投影
          → streamAssistantResponse()：变换、转换并规范化消息
          → streamFunction() → modelRuntime.streamSimple()
```

这里包含一次跨层回调：AgentSession 把 `prepareRequest` 安装到 Agent，AgentLoop 在请求边界调用它。消息因此会以当前会话投影刷新，不能把最终上下文简化为最初的“内存历史 + 用户输入”。

工具执行后还可能进入下一次模型请求；`prepareNextTurn` 会在后续响应前刷新消息、工具和指令选项。压缩、路由及扩展的完整实现留待专门模块，本篇标明它们的接入位置。

## 4. 验证范围

本模块及五个子页面均对照锁定的 Pi v1.0.0 源码编写。代码块标明实际函数或摘录位置；简化调用链省略旁支，不是可执行示例。未执行会话恢复、上游测试或真实模型请求；文档构建与预览只验证站点。
