# Pi 源码学习文档

本项目使用 VitePress 整理官方 `earendil-works/pi` 的源码学习过程，供检索与复习。学习内容以 Git 标签 `v1.0.0`、提交 `a13d35a74` 为基线；官方源码由项目根仓库通过 `pi/` Git 子模块锁定。涉及版本变化时，在对应文档中另行注明。

## 文档索引

| 顺序 | 文档 | 内容 | 验证状态 |
| --- | --- | --- | --- |
| 01 | [项目启动](01-项目启动.md) | 项目结构、Windows 源码启动、模型数据、认证、启动链路、问题处理与实测记录 | CLI、RPC、Bash 已验证；交互界面与真实模型对话待验证 |

## 阅读与维护约定

- 先读每篇的快速操作，再按问题编号查阅排障记录。
- 文档站命令在项目的 `docs/` 执行；Pi 源码命令在 `pi/` 执行。历史启动笔记中的“仓库根目录”和旧绝对路径指当时的 Pi 源码目录。
- 明确区分“实际执行结果”“源码分析结论”和“待验证操作”。失败及处理过程保留在原文中。
- 后续按 `02-主题.md`、`03-主题.md` 添加文档并更新本索引；每篇记录版本、日期、源码入口和验证边界。
- 学习笔记放在本目录；上游原始使用文档保留在 [`packages/coding-agent/docs`](../../packages/coding-agent/docs/index.md)。
- 不在文档或版本库保存 API Key、OAuth Token、私人会话或本机认证文件。
