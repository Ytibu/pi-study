## 目录与阅读约定

本文档中的路径以 `pi-study/` 项目根目录为起点：

```text
pi-study/
├── docs/
│   ├── learning/       # 学习笔记与本站首页
│   └── .vitepress/    # 文档站配置
└── pi/                # 官方 Pi v1.0.0 源码
    └── packages/      # CLI、代理运行时、模型适配、终端界面等包
```

- **查看文档站**：在 `docs/` 安装依赖并运行 `npm run dev`。
- **运行 Pi 源码**：从 [项目启动](01-项目启动.md) 开始，相关命令在 `pi/` 执行。
- **查阅上游用法**：见 [官方使用文档](../../pi/packages/coding-agent/docs/index.md)。

笔记分别标明源码分析、历史实测和待验证操作；文档构建通过仅表示站点构建成功。认证信息和私人会话不写入文档或版本库。
