# 04.1 历史消息

版本：Pi **v1.0.0**（`a13d35a74`） · 记录日期：2026-10-25

所属模块：[04 消息历史与上下文准备](04-消息历史与上下文准备.md)。本篇说明消息如何保存、恢复，以及当前输入如何接到历史后面。

## 1. 消息记录什么

历史消息保存此前交互的内容与角色。模型再次收到这些信息，才能理解“继续”“刚才那个文件”等依赖前文的输入。

| `role` | 内容 |
| --- | --- |
| `system` | 系统指令、指令分区与工具声明的变化 |
| `user` | 用户任务，内容可以包含文字或图片 |
| `assistant` | 模型输出，包括文字与工具调用 |
| `toolResult` | 工具执行结果，通过 `toolCallId` 对应此前调用 |

例如，用户说“再简短一点”，需要结合前一条 assistant 回复才能判断要简化什么。工具调用和工具结果也必须保留对应关系，不能只保存聊天文字。

## 2. 当前输入如何变成消息

在 [AgentSession.prompt()](../../pi/packages/coding-agent/src/core/agent-session.ts) 中，普通输入经过输入处理、模板展开等步骤后，被组装成 `user` 消息。下面是结构示意：

```json
{
  "role": "user",
  "content": [{ "type": "text", "text": "再简短一点" }],
  "timestamp": 0
}
```

`role` 表示来源，`content` 保存内容，`timestamp` 记录时间；示例中的 `0` 是占位值。直接调用底层 `Agent.prompt(string)` 时，也会由 `normalizePromptInput()` 完成类似转换。

## 3. 历史在哪里

Pi 中需要区分三层数据：

| 数据 | 作用 |
| --- | --- |
| `SessionManager` 的会话条目 | 保存消息、模型选择、压缩记录等，并用 `id`、`parentId` 组成分支结构 |
| `agent.state.messages` | 保存当前 Agent 的内存消息历史 |
| 请求使用的消息 | 在当前历史和新消息基础上，经转换整理后交给模型 |

会话启用持久化时使用 JSONL 文件保存条目；也支持纯内存会话。会话文件中的所有条目不会原样发送给模型。

### 3.1 恢复已有会话

```text
SessionManager.buildSessionContext()
  → 按当前叶节点选择分支
  → 应用压缩与上下文编辑等记录
  → 得到当前有效消息
  → createAgentSession() 用它初始化 Agent
```

例如会话从同一个问题分出两个回答方向时，当前请求沿所选分支恢复；另一个分支仍可保存在会话中。发生压缩后，请求可能使用摘要和保留的消息，而非全部旧正文。

### 3.2 加入新消息

[runAgentLoop()](../../pi/packages/agent/src/agent-loop.ts) 将运行快照中的历史与本次新消息合并：

```text
运行中的消息 = 已有历史 + 本次消息（可能包含 system 更新和 user 输入）
```

循环为新消息发出 `message_end` 等事件；`Agent.processEvents()` 将完成的消息加入内存状态，`AgentSession` 再交给 `SessionManager` 记录。后续的模型回复和工具结果也通过消息事件进入历史。

因此，“加入历史”包括内存状态更新与会话记录两个层次，不需要先把输入写入磁盘、再从磁盘读回来才能请求模型。

## 4. 源码入口

| 源码 | 阅读重点 |
| --- | --- |
| [session-manager.ts](../../pi/packages/coding-agent/src/core/session-manager.ts) | `appendMessage()` 包装条目；`buildSessionProjection()`、`buildSessionContext()` 恢复当前有效消息 |
| [sdk.ts](../../pi/packages/coding-agent/src/core/sdk.ts) | 将 `existingSession.messages` 放入 Agent 初始状态 |
| [agent-session.ts](../../pi/packages/coding-agent/src/core/agent-session.ts) | `prompt()` 组装用户消息；消息事件处理中调用 `appendMessage()` |
| [agent.ts](../../pi/packages/agent/src/agent.ts) | `createContextSnapshot()` 取得历史；`processEvents()` 更新内存消息 |
